📋 Enunciado y Query

🎯 Objetivo

Encontrar empleados que cumplan con múltiples criterios simultáneamente utilizando operaciones de conjuntos.

📝 Descripción

Necesitamos obtener información de empleados que:

  • Tienen asignado un departamento
  • Han tenido el rol "Technical Lead" en algún proyecto
  • Ganan más que el promedio global de salarios
  • Nunca han sido "Project Manager"

💻 Query SQL

SELECT e.id, e.first_name, e.last_name, e.salary FROM employees e WHERE /* A: pertenece al conjunto "tiene departamento" */ e.department_id IS NOT NULL /* B: pertenece al conjunto "tiene rol Technical Lead" */ AND EXISTS ( SELECT 1 FROM employee_project ep WHERE ep.employee_id = e.id AND ep.role = 'Technical Lead' ) /* C: pertenece al conjunto "salario > promedio global" */ AND e.salary > ( SELECT AVG(e2.salary) FROM employees e2 ) /* D: excluir conjunto "es Project Manager" */ AND NOT EXISTS ( SELECT 1 FROM employee_project ep2 WHERE ep2.employee_id = e.id AND ep2.role = 'Project Manager' );
💡 Fórmula de Conjuntos:
Resultado = (A ∩ B ∩ C) - D

🏷️ Leyenda

A: Departamento
B: Technical Lead
C: Salario > Prom
D: Project Manager (excluir)

📊 Diagrama Interactivo

📊 Todos los Empleados

Conjunto inicial de la tabla employees.

✅ Paso 1: Conjunto A (Departamento)

Empleados que tienen asignado un departamento.

WHERE e.department_id IS NOT NULL

✅ Paso 2: A ∩ B (Technical Lead)

Intersección con empleados que tienen el rol "Technical Lead" en algún proyecto.

AND EXISTS (SELECT 1 FROM employee_project WHERE role = 'Technical Lead')

✅ Paso 3: A ∩ B ∩ C (Salario Alto)

Intersección con empleados con salario superior al promedio global.

AND e.salary > (SELECT AVG(salary) FROM employees)

❌ Paso 4: (A ∩ B ∩ C) - D (Excluir Project Managers)

Excluir empleados que son o fueron "Project Manager".

AND NOT EXISTS (SELECT 1 FROM employee_project WHERE role = 'Project Manager')

🎯 Resultado Final

Technical Leads de alto salario sin experiencia como Project Manager

  • ✓ Tienen departamento asignado
  • ✓ Son Technical Lead en algún proyecto
  • ✓ Salario > promedio global
  • ✗ NO son Project Manager

📋 Enunciado y Query

🎯 Objetivo

Identificar empleados operativos que participan en proyectos, sin ser Project Manager ni pertenecer a departamentos administrativos.

📝 Descripción

Necesitamos obtener empleados que:

  • Participan en al menos un proyecto
  • NO son "Project Manager" en ningún proyecto
  • NO pertenecen a departamentos administrativos (1, 2, 9)

💻 Query SQL

SELECT * FROM employees e WHERE /* Participa en al menos un proyecto */ EXISTS ( SELECT 1 FROM employee_project ep WHERE ep.employee_id = e.id ) /* Excluir a los "Project Manager" */ AND NOT EXISTS ( SELECT 1 FROM employee_project ep2 WHERE ep2.employee_id = e.id AND ep2.role = 'Project Manager' ) /* Excluir departamentos administrativos */ AND NOT EXISTS ( SELECT 1 FROM departments d WHERE d.id = e.department_id AND d.id IN (1,2,9) );
💡 Fórmula de Conjuntos:
Resultado = (Empleados ∩ En_Proyecto) - Project_Manager - Deptos_Admin

🏢 Departamentos Excluidos

  • ❌ 1 - Human Resources
  • ❌ 2 - Finance
  • ❌ 9 - Legal
  • ✅ 3, 4, 5... - Technology, Marketing, Sales, etc. (permitidos)

🏷️ Leyenda

Emp: Empleados
Proy: En Proyecto
PM: Project Manager
Admin: Deptos 1,2,9
