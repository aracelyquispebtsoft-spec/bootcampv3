CSS · Responsive Design · Clase interactiva

Diseñar para el espacio disponible

Responsividad no significa “hacer todo más pequeño”. Significa permitir que contenido, layout, texto e imágenes se adapten de forma comprensible a distintos espacios.

🗣 Pregunta para iniciar la clase
“Si una página se ve bien a 375px y a 1440px, ¿significa que ya es responsiva?” La respuesta es: no necesariamente. También debemos revisar todo lo que ocurre entre esos tamaños.
01 · Estrategia

Mobile First

Escribe primero una base simple para espacios pequeños. Después agrega mejoras a medida que aparece espacio suficiente.

CSS base → mejoras progresivas

.cards {
  display: grid;
  grid-template-columns: 1fr;
}

@media (min-width: 48rem) {
  .cards {
    grid-template-columns: repeat(2, 1fr);
  }
}
Idea: el CSS sin media query ya debe funcionar. La media query mejora el diseño; no debería “rescatarlo”.

02 · Layout unidimensional

Flexbox

Flexbox organiza elementos principalmente en una fila o una columna y distribuye el espacio de forma flexible.

.actions {
  display: flex;
  flex-wrap: wrap;
  gap: 0.75rem;
}

Consejos

✓ Usa gap para separar hijos.
✓ Usa flex-wrap si pueden saltar de línea.
✓ Aprovecha flex-grow y flex-shrink antes de fijar anchos.

Evita: construir layouts normales con position:absolute. Sácalo del flujo solo cuando realmente necesites superposición.
03 · Layout bidimensional

CSS Grid

Grid es excelente para dashboards, tarjetas, galerías y layouts donde filas y columnas importan al mismo tiempo.

Grid adaptable sin muchos breakpoints

.grid {
  display: grid;
  grid-template-columns:
    repeat(auto-fit, minmax(14rem, 1fr));
  gap: 1rem;
}

Con auto-fit + minmax(), el navegador decide cuántas columnas caben sin obligarnos a crear un breakpoint para cada cambio.

✓ ¿Flex o Grid?
Regla didáctica: Flexbox suele resolver mejor una dirección; Grid suele ser más natural cuando necesitas controlar filas y columnas. No es una ley: pueden combinarse.
04 · Cambios por viewport

Media Queries

Una media query aplica CSS cuando se cumple una condición. En responsive design, una de las condiciones más comunes es el ancho del viewport.

Simulador de ancho
Mueve el control. El layout cambia cuando el contenido lo necesita.

Usuarios

Ventas
✓ Pocos breakpoints

No hace falta tener una media query por cada dispositivo.

✓ Solo lo que cambia

No repitas dentro de la media query propiedades que ya son correctas.

✓ Prueba entre puntos

Un bug puede aparecer a 690px aunque 640px y 768px se vean bien.

05 · Escala flexible

Unidades relativas

Las unidades relativas ayudan a que texto, espacios y cajas respondan a su contexto en lugar de depender siempre de un número fijo de píxeles.

Explorador de unidades
70%Relativo al ancho del contenedor.
Unidad / funciónÚtil para
%Anchos relativos al contenedor
remTipografía y espaciado consistente
emEscala relativa al contexto tipográfico
vw/vhDimensiones relacionadas al viewport
min()/max()Elegir límites dinámicos
clamp()Mínimo + valor fluido + máximo
.title {
  font-size: clamp(2rem, 5vw, 4rem);
}

.container {
  width: min(90%, 75rem);
}
06 · Multimedia

Imágenes responsivas

Una imagen debe respetar el espacio disponible, mantener su proporción cuando corresponde y no obligar al layout a desbordarse.

object-fit
object-fit: cover
img {
  max-width: 100%;
  height: auto;
  display: block;
}

.card-image {
  width: 100%;
  aspect-ratio: 16 / 9;
  object-fit: cover;
}

Para rendimiento y diferentes resoluciones, HTML también ofrece srcset, sizes y <picture>.

Consejo: no descargues una imagen enorme para mostrarla como miniatura en móvil si puedes ofrecer una versión más adecuada.
07 · Componentes modernos

Container Queries

Las media queries preguntan por el viewport. Las container queries permiten que un componente responda al espacio de su contenedor.

Arrastra el borde derecho ↔
La Card decide su layout
🧩

Componente reutilizable

Puede vivir en un sidebar estrecho o en una zona principal ancha.

.card-container {
  container-type: inline-size;
}

.card {
  display: flex;
  flex-direction: column;
}

@container (min-width: 520px) {
  .card {
    display: grid;
    grid-template-columns: 180px 1fr;
  }
}
Pregunta clave:
@media → “¿cuánto mide la pantalla?”
@container → “¿cuánto espacio tiene este componente?”
Código limpio · Responsive

Que responda bien y también se pueda mantener

El código responsive se vuelve difícil de mantener cuando acumula números mágicos, media queries duplicadas, selectores muy específicos y excepciones.

✗ Difícil de mantener

.card {
  width: 437px;
  margin-left: 27px;
  padding: 19px;
}

@media (min-width: 783px) {
  .card {
    width: 640px;
  }
}

✓ Más flexible

:root {
  --space-md: 1rem;
  --card-max: 30rem;
}

.card {
  width: 100%;
  max-width: var(--card-max);
  padding: var(--space-md);
}
